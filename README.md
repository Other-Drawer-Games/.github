# .github

Organisation profile and GitHub community configuration for Other Drawer Games.

Contributors follow the canonical [development practices](https://github.com/Other-Drawer-Games/other-drawer-games/blob/main/docs/development/README.md)
and [design and experience philosophy](https://github.com/Other-Drawer-Games/other-drawer-games/blob/main/docs/DESIGN_EXPERIENCE_PHILOSOPHY.md).
Publisher-facing changes use the central [design contract](https://github.com/Other-Drawer-Games/other-drawer-games/blob/main/DESIGN.md)
and [rendered UX review stage](https://github.com/Other-Drawer-Games/other-drawer-games/blob/main/docs/development/EXPERIENCE_REVIEW.md).
The public profile lives in `profile/`; this repository has no application runtime.
